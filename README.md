# Transaction Analyzer

Приложение для анализа банковских транзакций из Excel-файла.  
Генерирует JSON-данные для веб-страниц, формирует отчёты и предоставляет аналитические сервисы.

## Возможности

- **Приветствие** – зависит от времени суток (утро/день/вечер/ночь).
- **Главная страница** – сводка по картам, последние 5 транзакций, курсы валют, котировки акций.
- **Аналитика расходов** – разбивка по категориям за месяц (топ-7 + «Остальное», переводы и наличные отдельно).
- **Кешбэк** – топ-3 категории с наибольшим кешбэком за текущий месяц.
- **Поиск** – простой поиск по описанию транзакций (без учёта регистра), поиск телефонных номеров, поиск переводов физическим лицам.
- **Отчёты по категориям** – детализация расходов за последние 3 месяца с автосохранением в JSON.
- **Гибкие настройки** – список валют и акций задаётся в `user_settings.json`.
- **Генерация отчётов** – все данные собираются в единый JSON, отдельные функции могут сохранять результат в файл.

## Ключевые сервисы
* Простой поиск (simple_search): ищет подстроку в поле Описание, игнорируя регистр.

* Поиск телефонов (phone_search): распознаёт номера в форматах +7 (900) 000-00-00, 89000000000 и подобных.

* Поиск переводов (transfer_search): находит транзакции с переводами физическим лицам.

* Кешбэк (cashback_categories): рассчитывает топ-3 категории по сумме кешбэка за текущий месяц (предполагается наличие данных о проценте кешбэка).

## Требования
- Python 3.8+

- Poetry (рекомендуется) или pip

- Зависимости перечислены в pyproject.toml (pandas, openpyxl, requests, python-dotenv, pytest, pytest-cov, pytest-html)


## Установка

1. **Клонируйте репозиторий:**

   git clone https://github.com/yourusername/transaction-analyzer.git
   cd transaction-analyzer

2. Установите зависимости через Poetry:
```poetry install```

3. Настройте переменные окружения:
Скопируйте .env_template в .env и заполните ключи API:

EXCHANGE_RATE_API_KEY=ваш_ключ_exchangerate.host
FINNHUB_API_KEY=ваш_ключ_finnhub.io
Если ключи не указаны, курсы валют не будут загружены, а для акций вернутся нулевые значения.

Подготовьте данные:

Поместите Excel-файл operations.xlsx в папку data/.

Отредактируйте user_settings.json – укажите интересующие вас валюты и тикеры акций.

## Использование
1. Запустите главный модуль для генерации сводного JSON:
```poetry run python src/main.py```
В консоль будет выведен объект, содержащий:

- greeting

- main_page (информация о картах, последние транзакции, курсы валют, котировки акций, аналитика расходов)

- cashback_categories

- simple_search, phone_search, transfer_search

- category_report (пример по категории «Еда»)

При первом вызове spending_by_category автоматически создастся файл spending_by_category_report.json в корне проекта.

## Тестирование
Проект покрыт автоматическими тестами с использованием фреймворка pytest. Тесты расположены в директории tests/ и охватывают все основные модули.
Для запуска тестов используйте pytest:
```poetry run pytest tests/```
Отчёт о покрытии кода
```poetry run pytest tests/ --cov=src --cov-report=html```
После выполнения откройте htmlcov/index.html в браузере.

### Покрытие кода
На данный момент тесты покрывают 97% кода модулей проекта.

## Формат данных
Файл operations.xlsx должен содержать как минимум столбцы:

- Дата операции (формат даты, например dd.mm.yyyy)

- Категория

- Сумма платежа (расходы – отрицательные числа)

- Описание

- Номер карты (или другой идентификатор для группировки по картам)

### Настройки (user_settings.json)
Пример содержимого:

json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "GOOGL"]
}
